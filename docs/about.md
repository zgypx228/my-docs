# 关于本项目

## 项目目标

实现从 Markdown 文档到公开网站的自动化发布，做到"改完推送就上线"，中间不需要手动构建、不需要手动上传。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容 |
| MkDocs Material | 将文档构建成静态网站 |
| GitHub Actions | 自动执行安装、构建和部署 |
| GitHub Pages | 托管并提供网站访问地址 |

## 我的理解

这四样东西其实是流水线上的四道工位：Markdown 是原料，MkDocs 是加工机器，Actions 是按下开关的那只手，Pages 是最后把成品摆出来的展台。

值得注意的是 `site/` 目录：它每次构建都会重新生成，属于"产物"而不是"源码"。所以我把它写进 `.gitignore`，不让它进版本库——否则源码和产物会混在一起，谁也说不清哪份是准的。
